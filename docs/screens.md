# Brew Pick - 화면 설계서

## 1. 로그인 페이지 (`/login`)

```
┌──────────────────────────────────────────┐
│                                          │
│                                          │
│              ☕ Brew Pick                 │
│                                          │
│        매달 커피, 골라 마시자              │
│                                          │
│     ┌──────────────────────────┐         │
│     │  🔗 Google로 로그인       │         │
│     └──────────────────────────┘         │
│     * @ten1010.io 계정만 허용             │
│                                          │
│                                          │
└──────────────────────────────────────────┘
```

### 기능
| 기능 | 설명 |
|------|------|
| Google 로그인 버튼 | 클릭 시 Google OAuth 팝업, @ten1010.io 외 도메인은 로그인 거부 |
| 자동 리다이렉트 | 이미 로그인된 사용자는 방 목록(`/rooms`)으로 이동 |

## 2. 방 목록 페이지 (`/rooms`)

```
┌──────────────────────────────────────────┐
│  ☕ Brew Pick          [김준서] [로그아웃] │
├──────────────────────────────────────────┤
│                                          │
│  활성 방 목록              [+ 방 만들기]  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │ ☕ 오늘의커피           🔒         │  │
│  │ 투썸플레이스 · 김민수 · 5명 참여    │  │
│  │ 남은 시간: 8시간 32분              │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │ ☕ 4월 커피 투표                    │  │
│  │ 이디야 · 박지영 · 12명 참여         │  │
│  │ 남은 시간: 3시간 15분              │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │ ☕ 디자인팀 커피        🔒  종료됨  │  │
│  │ 투썸플레이스 · 이수현 · 8명 참여    │  │
│  │ (투표 종료)                        │  │
│  └────────────────────────────────────┘  │
│                                          │
│  방이 없나요? 새로운 방을 만들어보세요!   │
│                                          │
└──────────────────────────────────────────┘
```

### 기능
| 기능 | 설명 |
|------|------|
| 방 목록 | 생성 후 12시간 이내인 방만 표시 |
| 방 카드 정보 | 방 이름, 프랜차이즈, 생성자, 참여 인원 수, 남은 시간 |
| 🔒 표시 | 비밀번호가 설정된 방 |
| 종료됨 표시 | 방장이 조기 종료한 방 (입장은 가능하나 투표 불가) |
| + 방 만들기 | 방 생성 페이지로 이동 |
| 방 클릭 | 해당 방 입장 (비밀번호 방은 입력 모달 표시) |
| 사용자 정보 | 우측 상단에 로그인된 사용자 이름, 로그아웃 버튼 |

## 4. 방 생성 페이지 (`/rooms/new`)

```
┌──────────────────────────────────────────┐
│  ☕ Brew Pick          [김준서] [로그아웃] │
├──────────────────────────────────────────┤
│                                          │
│  ← 돌아가기                              │
│                                          │
│  새로운 방 만들기                         │
│                                          │
│  방 이름 *                               │
│  ┌──────────────────────────────────┐    │
│  │ 오늘의커피                        │    │
│  └──────────────────────────────────┘    │
│                                          │
│  비밀번호 (선택)                          │
│  ┌──────────────────────────────────┐    │
│  │                                  │    │
│  └──────────────────────────────────┘    │
│  비밀번호를 설정하면 입장 시 필요합니다     │
│                                          │
│  프랜차이즈 선택 *                        │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ ☕ 이디야  │ │ ☕ 투썸   │ │ ☕ 스타벅스│ │
│  │          │ │  ✅ 선택  │ │          │ │
│  └──────────┘ └──────────┘ └──────────┘ │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│  │ ☕ 메가   │ │ ☕ 컴포즈  │ │ ☕ 빽다방  │ │
│  │          │ │          │ │          │ │
│  └──────────┘ └──────────┘ └──────────┘ │
│  * 데스크톱 3~4열 / 모바일 2열 그리드     │
│                                          │
│  ┌──────────────────────────────────┐    │
│  │          방 만들기                │    │
│  └──────────────────────────────────┘    │
│                                          │
└──────────────────────────────────────────┘
```

### 기능
| 기능 | 설명 |
|------|------|
| 방 이름 입력 | 필수, 텍스트 입력 |
| 비밀번호 입력 | 선택사항, 설정하면 입장 시 비밀번호 필요 |
| 프랜차이즈 선택 | 필수, 그리드 카드형 UI로 하나만 선택 (데스크톱 3~4열, 모바일 2열) |
| 방 만들기 버튼 | 유효성 검사 후 방 생성, 생성된 방으로 자동 이동 |
| ← 돌아가기 | 방 목록으로 돌아감 |

## 화면 흐름도 (Flow)

```
  [로그인 페이지]
       │
       ▼ (Google OAuth)
  [방 목록 페이지] ◄────────────────────┐
       │                               │
       ├──── [+ 방 만들기] ────►[방 생성 페이지]
       │                          │
       │                          ▼ (생성 완료)
       │                     ┌────────────┐
       ▼ (방 클릭)           │            │
  ┌─────────────┐            │            │
  │ 비밀번호 방?│──Yes──►[비밀번호 모달]  │
  └─────────────┘            │            │
       │ No                  ▼            │
       ▼              (비밀번호 확인)      │
  [투표 페이지] ◄────────────┘◄───────────┘
       │
       ├── 투표 진행 중: 음료 선택 + 실시간 현황
       │
       ├── 방장: [투표 종료하기] → [종료 확인 모달]
       │
       ▼ (종료 또는 12시간 만료)
  [결과 페이지 (같은 URL, 상태만 변경)]
```

## 반응형 대응

| 화면 | 데스크톱 | 모바일 |
|------|---------|--------|
| 방 목록 | 카드 2~3열 | 카드 1열 |
| 방 생성 | 프랜차이즈 카드 가로 배치 | 세로 배치 |
| 투표 | 음료 카드 3~4열 그리드 | 2열 그리드 |
| 결과 | 막대 그래프 + 상세 목록 가로 배치 | 세로 배치 |

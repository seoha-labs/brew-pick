# Brew Pick - PRD (Product Requirements Document)

## 개요

회사에서 매달 제공하는 커피 복지를 위한 음료 투표 웹앱.
Google 계정으로 로그인하고, 방을 만들어 프랜차이즈 음료 중 하나를 투표하는 서비스.

## 핵심 기능

### 1. 인증
- Firebase Auth + Google OAuth를 통한 로그인
- 회사 Google Workspace 도메인(`@ten1010.io`)만 허용

### 2. 방(Room) 관리
- **생성**: 모든 로그인 사용자가 방 생성 가능
  - 방 이름 (예: "오늘의커피")
  - 비밀번호 (선택사항)
  - 프랜차이즈 선택 (방장만 가능)
- **유효시간**: 생성 시점 기준 12시간
  - 12시간 초과 시 조회 목록에서 제외 (데이터 삭제 X, 필터링)
  - 별도 배치 작업 없음
- **조기 종료**: 방장이 투표를 강제 종료 가능 (12시간 이내)

### 3. 프랜차이즈 & 메뉴
- 지원 프랜차이즈 (초기):
  - 이디야 커피
  - 투썸플레이스
- 메뉴 데이터: GitHub Actions에서 크롤링 → JSON 파일로 저장
- 빌드 시 정적 데이터로 포함

### 4. 투표
- 방에 입장한 사용자는 음료 목록에서 **1개만** 선택
- 투표 변경 가능 (종료 전까지)
- 방장이 종료하거나 12시간이 지나면 투표 불가

### 5. 결과
- 실시간 투표 현황 표시
- 누가 어떤 음료를 선택했는지 표시
- 음료별 투표 수 집계

## 비기능 요구사항

- 최대한 간단한 구조
- 서버리스 (Firebase Spark 무료 요금제)
- 정적 호스팅 (GitHub Pages)
- Cloud Functions 미사용 (무료 요금제 제약)
